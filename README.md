# EpicaGame

## Что это за проект?
Skalm - это многопользовательский слэшер в средневековом сеттинге, с открытым миром.

Сам проект представляет из себя RPG, где вам предстоит развивать своего персонажа, посредством прокачки снаряжения, а так же участвовать в захватывающих боях между игроками как в открытом мире, так и на полях сражений, таких как гладиаторские бои или войны за территорию среди гильдий!
